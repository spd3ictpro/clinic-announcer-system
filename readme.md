# Clinic Queue Management System

A web-based queue management system for clinics with voice announcement capabilities.

## Features

- **Queue Management**: Add, remove, and call patients
- **Voice Announcements**: Text-to-speech calls in Malay
- **Recall System**: Multiple calls for unresponsive patients
- **Statistics**: Track called patients, waiting count, and recalls
- **Responsive Design**: Works on desktop and mobile devices
- **Local Storage**: Saves queue data between sessions

[View on GitHub Pages][(https://your-username.github.io/clinic-queue-system/)](https://spd3ictpro.github.io/clinic-announcer-system/)

## How to Use

1. **Add Patient**: Enter patient name and counter number
2. **Call Patient**: Click "Call Next" to announce the next patient
3. **Recall Patient**: If patient doesn't respond, click "Recall Patient"
4. **Mark Arrived**: Click "Patient Arrived" when patient comes
5. **Manage Queue**: Remove patients or clear entire list
